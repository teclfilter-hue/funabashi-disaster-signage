# 避難情報HTML抽出の技術検証メモ

千葉県防災ポータルの実ページで次の形式を確認しています。

```text
船橋市 避難情報 発令:2026年09月6日 千葉県大雨警報・注意報 (...)
市内全域（内水浸水想定区域）：高齢者等避難 警戒レベル３ 発令( 2026/09/06 20:50 )
```

解除時は、例えば次の形式です。

```text
船橋市 避難情報 解除:令和８年台風第６号 (...)
市内対象地域：高齢者等避難 警戒レベル３ 解除( 2026/06/03 14:10 )
```

Workerの `parseEvacuationPage()` は、全角／半角の警戒レベル、発令／解除、対象地域、日時を正規化して処理します。

また、千葉県防災ポータルのトップには「船橋市」の避難情報詳細ページへのリンクが掲載されることを確認しています。

この検証は**公開HTMLの技術検証**であり、千葉県が第三者向けに正式公開したAPI仕様を意味するものではありません。
