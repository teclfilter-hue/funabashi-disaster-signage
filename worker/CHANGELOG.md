# 変更点

## 避難情報HTML技術検証追加版

- 既存 `/api/status` は変更しない
- 既存 `/api/chiba-disaster` は互換性を維持
- 新規 `/api/evacuation` を追加
- 千葉県防災ポータルの船橋市「避難情報」詳細ページを検出
- 公開HTMLから発令／解除、対象地域、警戒レベル、日時を抽出
- 警戒レベル3：高齢者等避難
- 警戒レベル4：避難指示
- 警戒レベル5：緊急安全確保
- 同一地域の発令／解除が混在する場合は最新日時を採用
- 代表3地域をサイネージ用に保持
- 取得エラーと「発令なし」を分離
- 避難情報発令時は気象情報より優先表示
- `?test=1&evacuation=3/4/5` を追加
- 正式JSON/API/XML/フィードが確認できた場合、取得部分だけを差し替え可能

## 公式情報の技術検証

千葉県防災ポータルの実ページで、例えば以下の形式を確認済みです。

```text
市内全域（内水浸水想定区域）：高齢者等避難 警戒レベル３ 発令( 2026/09/06 20:50 )
市内対象地域：高齢者等避難 警戒レベル３ 解除( 2026/06/03 14:10 )
```

この形式をWorkerの抽出処理で処理します。
